# IP Detector

Приложение для определения внешнего IP-адреса, получения
географической информации и загрузки результата на Яндекс.Диск.

## Возможности

- получение IP-адреса через ipify;
- получение географической информации через ipinfo;
- сохранение данных в JSON;
- создание папки `ip_detector` на Яндекс.Диске;
- загрузка JSON-файла через REST API Яндекс.Диска;
- автоматическое удаление временного локального файла.

## Требования

- Python 3.9 или новее;
- токен Яндекс.Диска;
- доступ к Интернету.
